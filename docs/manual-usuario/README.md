# Manual de uso oficial de TREBBIA

Versión: 2026-09-04  
Producto: TREBBIA, Centro Inteligente de Reservas y Agendamiento

Este manual explica cómo usar TREBBIA desde la perspectiva de un negocio que necesita organizar reservas, agenda, clientes, profesionales, servicios y recursos. Está escrito para propietarios, administradores, recepcionistas y profesionales.

TREBBIA no reemplaza los criterios operativos, comerciales o clínicos del negocio. La plataforma ayuda a ordenar información, citas y procesos; cada empresa es responsable de la información que registra.

## 1. Introducción

TREBBIA es una plataforma SaaS para negocios que trabajan con reservas o citas. Permite centralizar la agenda, registrar clientes, crear servicios, asignar profesionales, controlar recursos y compartir enlaces para que los clientes puedan reservar.

Puede ser utilizada por negocios como centros de fisioterapia, spas, centros de estética, veterinarias, barberías, consultorios, salones, restaurantes con reserva y otros negocios que necesitan organizar horarios.

El problema que resuelve es simple: evitar agendas dispersas, cruces de horarios, clientes duplicados y pérdida de control cuando las reservas llegan por diferentes canales.

## 2. Primeros pasos

### Crear cuenta

**¿Para qué sirve?**  
Permite crear el usuario principal que administrará el negocio.

**¿Qué debo hacer aquí?**  
Ingresa nombre, correo y contraseña en la pantalla de registro.

**¿Qué resultado debo esperar?**  
TREBBIA te llevará a crear o configurar tu negocio.

### Crear negocio

**¿Para qué sirve?**  
Define el espacio de trabajo de la empresa dentro de TREBBIA.

**¿Qué debo hacer aquí?**  
Registra nombre del negocio, tipo de negocio, correo, teléfono y zona horaria.

**¿Qué resultado debo esperar?**  
La plataforma crea un workspace independiente para ese negocio.

### Completar onboarding

**¿Para qué sirve?**  
Ayuda a dejar configurada la base mínima para empezar a agendar.

**¿Qué debo hacer aquí?**  
Completa los pasos de negocio, horarios, primer servicio, primer profesional y finalización.

**¿Qué resultado debo esperar?**  
Al terminar, podrás entrar al panel principal y empezar a usar la agenda.

### Orden recomendado de configuración

1. Configurar el perfil del negocio.
2. Definir horarios generales.
3. Crear servicios.
4. Crear profesionales.
5. Asignar servicios a profesionales.
6. Crear recursos si el negocio necesita controlar salas, camillas, cabinas, sillas o equipos.
7. Activar reservas públicas si deseas recibir reservas desde un enlace.
8. Configurar WhatsApp si deseas compartir un enlace directo de conversación.
9. Crear o importar clientes.
10. Empezar a registrar citas.

## 3. Inicio

**¿Para qué sirve este módulo?**  
Inicio muestra el estado general del negocio para comenzar la jornada con contexto.

**¿Qué debo hacer aquí?**  
Revisa los indicadores principales: citas de hoy, próximas citas, clientes, profesionales activos y servicios activos. También puedes abrir el centro de compartir reservas.

**¿Qué resultado debo esperar?**  
Debes entender rápidamente si el negocio ya está listo para recibir reservas y si hay citas próximas por atender.

### Información visible

- Citas de hoy.
- Próximas citas.
- Total de clientes.
- Profesionales activos.
- Servicios activos.
- Progreso del canal público de reservas.
- Checklist de activación.

### Recomendación de uso diario

Al iniciar el día, entra a Inicio y revisa si hay citas próximas. Si el negocio aún está en etapa de configuración, usa el checklist para completar los pasos pendientes.

## 4. Agenda

**¿Para qué sirve este módulo?**  
Agenda es el centro operativo de las citas. Permite ver, filtrar, crear, editar y archivar reservas.

**¿Qué debo hacer aquí?**  
Selecciona vista por día o semana, elige una fecha, filtra por profesional, servicio o estado, y crea nuevas citas cuando sea necesario.

**¿Qué resultado debo esperar?**  
Las citas guardadas aparecen en la agenda, relacionadas con cliente, profesional, servicio, fecha, hora y recurso si aplica.

### Vistas disponibles

- **Día:** muestra las citas de una fecha específica.
- **Semana:** muestra la distribución de citas de la semana.

### Filtros disponibles

- Fecha.
- Profesional.
- Servicio.
- Estado.

### Estados de cita

- **Programada:** cita registrada, pendiente de confirmación o gestión.
- **Confirmada:** cita aceptada por el negocio.
- **Cancelada:** cita que no se realizará.
- **Completada:** cita ya atendida.

### Crear una cita

**¿Para qué sirve?**  
Permite registrar una reserva manual cuando el cliente llama, escribe o agenda directamente con el negocio.

**¿Qué debo registrar?**

- Fecha.
- Hora inicial.
- Cliente, opcional.
- Servicio, obligatorio.
- Profesional, obligatorio.
- Recurso, opcional.
- Sede, opcional.
- Estado.
- Notas internas.

**¿Qué sucede después?**  
TREBBIA valida conflictos conocidos de disponibilidad. Si el horario es válido, guarda la cita y la muestra en Agenda.

### Editar o archivar una cita

En los listados, usa el icono de edición para modificar la cita. Usa el icono de archivar cuando la cita ya no deba estar activa. TREBBIA solicita confirmación antes de archivar.

## 5. Clientes

**¿Para qué sirve este módulo?**  
Clientes centraliza la información de las personas que reservan o reciben servicios.

**¿Qué debo hacer aquí?**  
Crea clientes, busca por nombre, correo, teléfono o documento, revisa su ficha y consulta su historial de citas.

**¿Qué resultado debo esperar?**  
Cada cliente queda disponible para relacionarlo con citas y, cuando aplique, con historia clínica.

### Información que puede almacenar

- Nombre, obligatorio.
- Correo, opcional.
- Teléfono, opcional.
- Documento, opcional.
- Fecha de nacimiento, opcional.
- Estado activo/inactivo.
- Notas internas.

### Ficha del cliente

La ficha muestra datos de contacto, actividad, notas internas, próxima cita e historial de citas. Desde allí también puedes crear una nueva cita para ese cliente.

### Historia clínica

Historia clínica aparece únicamente para negocios relacionados con salud o bienestar clínico, como fisioterapia, salud, spa, veterinaria, estética, medicina, odontología, psicología, terapia o rehabilitación.

No aparece para negocios como barberías u otros rubros no clínicos.

## 6. Historia clínica

**¿Para qué sirve este módulo?**  
Permite registrar información clínica u operativa de pacientes en negocios donde esto aplica.

**¿Qué debo hacer aquí?**  
Abre un paciente desde Clientes y registra una evolución o valoración.

**¿Qué resultado debo esperar?**  
El registro queda asociado al paciente, al profesional y, si se selecciona, a una cita específica.

### Información disponible

- Fecha.
- Profesional.
- Cita relacionada.
- Dolor de 0 a 10.
- Motivo de consulta.
- Impresión diagnóstica.
- Subjetivo.
- Objetivo.
- Plan de tratamiento.
- Evolución.
- Recomendaciones.
- Próximos pasos.
- Estado: borrador o finalizada.

### Recomendación práctica

Usa “Borrador” cuando el registro aún no está completo. Usa “Finalizada” cuando el profesional ya revisó la información.

## 7. Servicios

**¿Para qué sirve este módulo?**  
Un servicio representa lo que el negocio ofrece y lo que el cliente puede reservar.

**¿Qué debo hacer aquí?**  
Crea servicios con nombre, duración, precio, descripción y estado activo/inactivo.

**¿Qué resultado debo esperar?**  
El servicio queda disponible para crear citas y para reservas públicas si está activo.

### Ejemplos

- Fisioterapia: Valoración inicial, 60 minutos.
- Barbería: Corte + barba, 45 minutos.
- Spa: Masaje relajante, 60 minutos.

### Relación con profesionales

Un servicio puede estar relacionado con profesionales. Si un servicio tiene profesionales asignados, TREBBIA usa esa relación para validar quién puede atenderlo.

## 8. Profesionales

**¿Para qué sirve este módulo?**  
Profesionales representa a las personas que prestan servicios o atienden citas.

**¿Qué debo hacer aquí?**  
Registra nombre, especialidad o cargo, correo, teléfono, sede, servicios que atiende, estado y horarios.

**¿Qué resultado debo esperar?**  
El profesional queda disponible para la agenda y para la reserva pública si está activo.

### Diferencia entre usuario y profesional

- **Profesional:** persona que atiende servicios y aparece en la agenda.
- **Usuario:** persona que puede iniciar sesión en TREBBIA.

Una misma persona puede ser ambas cosas, pero no siempre es necesario. Por ejemplo, una recepcionista puede ser usuario sin ser profesional.

## 9. Recursos

**¿Para qué sirve este módulo?**  
Un recurso es algo que el negocio necesita reservar para poder prestar un servicio.

**¿Qué debo hacer aquí?**  
Crea recursos manualmente o usa recursos sugeridos según la actividad del negocio.

**¿Qué resultado debo esperar?**  
El recurso queda disponible para asociarse a citas y evitar cruces cuando se use en la agenda.

### Ejemplos

- Fisioterapia: camilla, consultorio, equipo de electroterapia.
- Spa: cabina, camilla.
- Barbería: silla, estación de trabajo.
- Restaurante: mesa, salón.

### Creación rápida

El módulo permite crear un recurso rápido con nombre, tipo, sede y estado activo.

### Recursos sugeridos

TREBBIA muestra sugerencias según la industria registrada en el negocio. Puedes seleccionar varios recursos y crearlos de una vez.

## 10. Horarios

**¿Para qué sirve este módulo?**  
Permite definir cuándo trabaja el negocio y, en módulos relacionados, cuándo trabaja cada profesional.

**¿Qué debo hacer aquí?**  
Configura días abiertos, hora de apertura y hora de cierre.

**¿Qué resultado debo esperar?**  
La disponibilidad de la agenda y las reservas se calculan con base en esos horarios.

### Horario del negocio vs horario del profesional

- **Horario del negocio:** define cuándo la empresa atiende en general.
- **Horario del profesional:** define cuándo una persona específica puede atender citas.

Si un profesional no trabaja determinado día, TREBBIA debe respetar esa disponibilidad al validar citas.

## 11. Sedes

**¿Para qué sirve este módulo?**  
Sedes permite administrar puntos de atención, sucursales o consultorios.

**¿Qué debo hacer aquí?**  
Desde Configuración > Sedes puedes crear o editar sedes con nombre, teléfono, dirección, estado y si es sede principal.

**¿Qué resultado debo esperar?**  
Las sedes quedan disponibles para relacionarlas con profesionales, recursos y citas.

## 12. Automatizaciones

**¿Para qué sirve este módulo?**  
Automatizaciones permite controlar recordatorios asociados a citas.

**¿Qué debo hacer aquí?**  
Puedes crear plantillas, programar recordatorios para citas futuras y marcar recordatorios como enviados u omitidos.

**¿Qué resultado debo esperar?**  
TREBBIA deja un registro operativo del recordatorio. Actualmente funciona como control interno/manual y base para futuras integraciones reales de envío.

### Disponible actualmente

- Plantillas de recordatorio.
- Canales seleccionables: manual, email y WhatsApp.
- Programación de recordatorios.
- Estado pendiente, enviado u omitido.
- Registro del mensaje generado.

### Importante

Aunque se pueden seleccionar email o WhatsApp como canal, el módulo actual sirve como control operativo. No debe presentarse como envío automático completo si la integración real no está conectada.

## 13. Compartir reservas

**¿Para qué sirve este módulo?**  
Centraliza los enlaces, QR y mensajes sugeridos para que el negocio comparta su canal de reserva.

**¿Qué debo hacer aquí?**  
Copia el enlace público, abre la experiencia del cliente, comparte el QR o usa los mensajes sugeridos para WhatsApp, Instagram o respuesta manual.

**¿Qué resultado debo esperar?**  
El cliente podrá abrir la página pública de reservas o iniciar una conversación por WhatsApp, según lo que el negocio tenga configurado.

### Elementos disponibles

- Enlace de reserva web.
- Enlace de WhatsApp si el número está configurado.
- QR de página pública.
- QR de WhatsApp si el canal está activo.
- Mensajes sugeridos.
- Checklist de activación.

## 14. WhatsApp

TREBBIA tiene dos niveles de WhatsApp: el modo actualmente disponible para uso comercial inmediato y la automatización asistida.

### Disponible actualmente

- Configurar número de WhatsApp del negocio.
- Generar enlace directo a WhatsApp.
- Generar QR de WhatsApp.
- Definir mensaje inicial.
- Mostrar botón o acceso desde la experiencia pública.
- Simulador interno de conversación para demos y pruebas.

### Automatización asistida

TREBBIA tiene base técnica para Meta Cloud API, pero su activación real requiere configuración administrada. No debe venderse como automático para todos los negocios hasta que esté conectado y probado para cada caso.

### Recomendación comercial actual

Para empezar a vender, ofrece:

1. Agenda y reservas públicas.
2. Enlace directo por WhatsApp.
3. Control de citas en TREBBIA.
4. Activación asistida de WhatsApp automático como servicio adicional.

## 15. Reportes

**¿Para qué sirve este módulo?**  
Reportes muestra indicadores básicos del negocio en un rango de fechas.

**¿Qué debo hacer aquí?**  
Selecciona fecha inicial y fecha final para revisar la información del periodo.

**¿Qué resultado debo esperar?**  
Obtendrás una visión rápida de citas, ingresos estimados, servicios más reservados, carga por profesional, próximas citas y clientes recientes.

### Indicadores disponibles

- Citas.
- Citas completadas.
- Citas canceladas.
- Ingresos estimados.
- Ticket promedio.
- Servicios más reservados.
- Carga por profesional.
- Próximas citas.
- Clientes recientes.

## 16. Membresía

**¿Para qué sirve este módulo?**  
Permite consultar el plan del negocio, uso actual, límites y estado comercial.

**¿Qué debo hacer aquí?**  
Revisa el plan actual, el periodo, los límites y las funciones incluidas.

**¿Qué resultado debo esperar?**  
El negocio puede entender su nivel de uso y qué incluye su membresía.

### Disponible actualmente

- Estado de suscripción.
- Plan actual.
- Fecha de periodo.
- Uso del plan.
- Planes disponibles.
- Cambio manual de plan.

### Importante

La pasarela de pago no está documentada como disponible porque la interfaz indica que la conexión de pagos se hará en una fase posterior.

## 17. Configuración

**¿Para qué sirve este módulo?**  
Configuración agrupa los ajustes principales del negocio.

**¿Qué debo hacer aquí?**  
Usa las pestañas para editar solo el bloque que necesitas.

**¿Qué resultado debo esperar?**  
Los cambios guardados afectan cómo se comportan la agenda, reservas públicas, WhatsApp, sedes y usuarios.

### Pestañas actuales

#### Perfil

Permite editar nombre, industria, correo, teléfono, zona horaria y moneda.

#### Agenda

Permite configurar intervalo de agenda, aviso mínimo para reservar, reservas públicas, confirmación manual y preferencias de notificación.

#### WhatsApp

Permite activar reservas por WhatsApp, definir número, nombre visible, estado de cita creada por WhatsApp, mensaje inicial y textos base.

También incluye una sección de activación automática asistida con Meta Cloud API.

#### Sedes

Permite crear y editar sedes.

#### Equipo

Permite invitar usuarios, asignar roles, vincular profesionales y revisar invitaciones pendientes.

## 18. Roles de usuario

TREBBIA contempla estos roles:

- **Owner:** responsable principal del negocio y su configuración.
- **Admin:** usuario con capacidad de gestión amplia.
- **Receptionist:** usuario orientado a agenda, clientes y reservas.
- **Professional:** usuario asociado a atención o prestación de servicios.

Actualmente la interfaz muestra la base de roles y usuarios, pero no conviene prometer una matriz avanzada de permisos si aún no se ha terminado de detallar.

## 19. Flujos completos

### Ejemplo 1: configurar un negocio por primera vez

1. Crear cuenta.
2. Crear negocio.
3. Completar datos básicos.
4. Configurar horarios.
5. Crear servicios.
6. Crear profesionales.
7. Asignar servicios a profesionales.
8. Crear recursos si aplica.
9. Activar reservas públicas.
10. Compartir el enlace con clientes.

Resultado esperado: el negocio queda listo para recibir y gestionar citas.

### Ejemplo 2: agendar una cita manual

1. Entrar a Agenda.
2. Seleccionar “Nueva cita”.
3. Elegir fecha y hora.
4. Seleccionar cliente, si ya existe.
5. Seleccionar servicio.
6. Seleccionar profesional.
7. Seleccionar recurso o sede si aplica.
8. Guardar.

Resultado esperado: TREBBIA valida disponibilidad y muestra la cita en Agenda.

### Ejemplo 3: atender una solicitud por WhatsApp en modo enlace

1. El negocio comparte el enlace de WhatsApp desde Compartir reservas.
2. El cliente escribe por WhatsApp.
3. El negocio conversa con el cliente.
4. El negocio registra o confirma la cita en TREBBIA.
5. La cita queda visible en Agenda.

Resultado esperado: WhatsApp sirve como canal de conversación y TREBBIA como control de agenda.

### Ejemplo 4: inicio de jornada

1. Entrar a Inicio.
2. Revisar citas de hoy.
3. Revisar próximas citas.
4. Abrir Agenda para ver detalle.
5. Atender cambios, cancelaciones o nuevas reservas.

Resultado esperado: el usuario entiende qué debe atender durante el día.

### Ejemplo 5: registrar historia clínica en fisioterapia

1. Entrar a Clientes.
2. Abrir el paciente.
3. Ir a Historia clínica dentro de la ficha.
4. Registrar motivo, dolor, impresión, plan, evolución y recomendaciones.
5. Guardar como borrador o finalizada.

Resultado esperado: el registro queda asociado al paciente y puede consultarse después.

## 20. Preguntas frecuentes

### ¿Debo crear primero el servicio o el profesional?

Puedes crear ambos en cualquier orden, pero lo ideal es crear primero servicios y luego profesionales para asignar qué atiende cada persona.

### ¿Qué diferencia hay entre cliente y profesional?

El cliente reserva o recibe el servicio. El profesional atiende la cita.

### ¿Qué diferencia hay entre usuario y profesional?

El usuario inicia sesión en TREBBIA. El profesional aparece en la agenda como persona que atiende servicios.

### ¿Para qué sirve un recurso?

Sirve para controlar elementos limitados como salas, camillas, cabinas, equipos o mesas.

### ¿Puedo modificar una cita?

Sí. Desde Agenda puedes abrir la cita con el icono de edición y actualizar fecha, hora, servicio, profesional, recurso, sede, estado o notas.

### ¿Puedo archivar una cita?

Sí. Usa el icono de archivar. TREBBIA pide confirmación antes de hacerlo.

### ¿Cómo bloqueo un horario?

La app tiene base de validación de bloqueos, pero el manual no documenta una pantalla completa de gestión de bloqueos si no está visible como flujo principal.

### ¿Qué ocurre si un profesional no trabaja determinado día?

TREBBIA usa horarios para validar disponibilidad. Si el horario del profesional no permite atender, la cita debe mostrar advertencia o impedirse según la validación disponible.

### ¿WhatsApp ya agenda solo?

Actualmente puedes compartir enlace y QR de WhatsApp, y existe un simulador interno. La automatización real por Meta Cloud API requiere activación asistida.

### ¿Historia clínica aparece para todos?

No. Solo aparece para negocios de salud o bienestar clínico.

## 21. Buenas prácticas

- Mantén horarios actualizados.
- Crea servicios con duración realista.
- Asigna servicios a los profesionales correctos.
- Evita duplicar clientes con el mismo teléfono.
- Usa recursos cuando haya elementos limitados.
- Revisa Inicio al comenzar la jornada.
- Revisa Agenda antes de confirmar cambios por WhatsApp.
- En negocios clínicos, registra evolución después de cada atención.
- No prometas automatizaciones reales hasta que estén conectadas y probadas.

## 24. Hallazgos durante la documentación

La elaboración del manual funcionó como una segunda auditoría UX. Estos hallazgos aparecen porque algunas funciones requieren explicación adicional para que un usuario nuevo las entienda.

### Configuración de WhatsApp

**Problema:** existe modo enlace, simulador y activación asistida; puede confundirse con WhatsApp automático listo para todos.  
**Impacto:** el cliente puede esperar respuestas automáticas reales antes de que Meta Cloud API esté activado.  
**Mejora sugerida:** mostrar una etiqueta más clara: “WhatsApp por enlace” y “WhatsApp automático asistido”.

### Automatizaciones

**Problema:** permite seleccionar email y WhatsApp como canales, pero opera como control/registro interno si no hay integración real.  
**Impacto:** el usuario podría creer que el mensaje se envía automáticamente.  
**Mejora sugerida:** agregar texto inline o badge “control manual” junto a los canales no conectados.

### Bloqueos de horario

**Problema:** la validación existe a nivel de disponibilidad, pero el flujo visible para gestionar bloqueos no está claramente documentable desde el menú.  
**Impacto:** el usuario puede no saber cómo cerrar espacios por almuerzo, ausencia o mantenimiento.  
**Mejora sugerida:** crear una pantalla visible de “Bloqueos” dentro de Agenda o Configuración.

### Recursos

**Problema:** el concepto puede ser difícil para usuarios no técnicos.  
**Impacto:** algunos negocios pueden omitir recursos y luego tener cruces de salas/equipos.  
**Mejora sugerida:** agregar ejemplos por industria dentro del módulo, con lenguaje corto.

### Roles

**Problema:** los roles existen, pero los permisos detallados no están explicados en la interfaz.  
**Impacto:** el Owner puede no saber qué puede hacer cada usuario invitado.  
**Mejora sugerida:** agregar descripciones breves junto al selector de rol.

### Historia clínica

**Problema:** es útil para salud, pero requiere una explicación clara de que no sustituye responsabilidad profesional.  
**Impacto:** riesgo de expectativas incorrectas en centros clínicos.  
**Mejora sugerida:** agregar aviso breve dentro del módulo y plantillas por tipo de atención.

### Capturas del manual

**Problema:** no hay flujo automatizado de capturas documentales.  
**Impacto:** mantener el manual visual actualizado será manual y puede quedar desfasado.  
**Mejora sugerida:** crear una tarea de capturas con Playwright o Laravel Dusk usando datos demo.
